# NovaRelay 评测指标说明

项目不在文档中预填“漂亮数字”。所有结果由 `evaluation/suites/*.json` 与实际运行环境生成。

| 指标 | 含义 | 趋势 |
|---|---|---|
| `case_pass_rate` | 所有场景断言全部通过的比例 | 越高越好 |
| `intent_accuracy` | 有意图标注的样本中预测正确的比例 | 越高越好 |
| `routing_accuracy` | 有路由标注的样本中 Agent 选择正确的比例 | 越高越好 |
| `error_rate` | 执行器异常的用例比例 | 越低越好 |
| `p50_latency_ms` | 中位响应延迟 | 越低越好 |
| `p95_latency_ms` | 95 分位响应延迟 | 越低越好 |

对外展示结果时，至少同时提供：Git commit、suite 文件、模型名称、运行时间、机器或容器环境、JSON/Markdown 报告。只有相同口径下的结果才适合比较。
